ℹ Welcome

Manage Intel GPU SR-IOV virtual machines. Use + Create VM to install a guest, and Configure to provision SR-IOV and tune launch parameters.

ⓘ Getting Started
ⓘ Follow these steps to go from a fresh host to a running GPU-accelerated VM.
1
⚙ Provision SR-IOV
Enable Virtual Functions on your Intel GPU by selecting a vGPU profile. Click the SR-IOV status in the sidebar or use the edit button to provision.
2
+ Create a VM
Install a new Ubuntu or Windows virtual machine.
3
⚙ Configure the VM
Set launch parameters. Use Auto Configure to load defaults based on characterization.
4
🚀 Launch the VM
Select the VM from the sidebar list, then use Start to launch it with GPU passthrough.
